🏥 Doctor Portal - Patient Management System

A simple, clean, and efficient web application built with React designed for private doctors to manage their practice. This portal streamlines patient tracking, appointment scheduling, and record management in a user-friendly interface.

🚀 Features

🔐 Authentication
- Doctor Sign Up: Register with Name, Email, Phone, Specialty, and Password.
- Secure Sign In: Simple login via Email and Password.
- Protected Routes: Redirects verified doctors to their personalized dashboard.

📊 Dashboard
- Search Patient: Quickly find patients by name or phone number to view their details.
- Add Patient: A streamlined form to register new patients into the system.
- View Patients: A clean, tabular view of all registered patients.
- Add Appointment: Create and schedule appointments linked to specific patients.
- Upcoming Appointments: An organized view of scheduled visits to keep track of the daily agenda.

👤 Patient Management
Each patient record includes comprehensive details:
- Full Name
- Age
- Contact Information
- Medical History/Notes

🛠️ Tech Stack
- Frontend: React (Vite or Create React App)
- Routing: React Router DOM
- Styling: CSS / Tailwind CSS / Styled Components
- State Management: React Hooks / Context API
